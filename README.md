# Wrist Relay

Gets Pixel phone notifications onto a OnePlus Watch over Wi-Fi when the watch is away from the phone.

This repo only holds release files. The apps check the latest release for updates:

- `phone.apk` installs on the phone
- `watch.apk` installs on the watch
- `version.json` tells the apps what the newest version is

The apps won't work without the private push key, which isn't included here.
